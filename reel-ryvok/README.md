# РЫВОК — рекламный рилс (Remotion, 1080×1920, 27 с, 30 fps)

**Результат:** [`out/ryvok-reel.mp4`](out/ryvok-reel.mp4) — H.264 + AAC, 27 с.

Продукт вымышленный: **«РЫВОК» — личное наставничество на 30 дней**. Тон дерзкий и прямой,
призыв — «ссылка в профиле». Название, слоган и ник меняются в `src/theme.ts`
(`BRAND`, `TAGLINE`, `NICK`); сейчас ник — заглушка `@твой_ник`.
В тексте нет выдуманных цифр, отзывов и обещаний результата.

## Сценарий
| Время | Голос и субтитры | Картинка |
|---|---|---|
| 0–2.5 с | Опять начнёшь с понедельника? | лист календаря «ПН» с первого кадра |
| 2.5–7 с | Ты говоришь это уже год. Спортзал. Английский. Своё дело. | 12 листов-месяцев, три плана зачёркиваются |
| 7–10 с | Проблема не в лени. У тебя нет системы. | «ЛЕНИ» рассыпается, появляется сетка и «СИСТЕМЫ» |
| 10–13 с | Рывок. Личное наставничество на 30 дней. | логотип, слоган, плашка «30 ДНЕЙ» |
| 13–20 с | Одна цель. План на каждый день. И человек, который не даст слиться. | мишень, сетка 30 дней, чат с наставником |
| 20–23 с | Понедельник не наступит. Начни сегодня. | «ПН» перечёркнут, «НАЧНИ СЕГОДНЯ» |
| 23–27 с | Ссылка в профиле. | логотип, кнопка, ник |

Весь текст держится в зоне 270–1480 px по вертикали, вне интерфейса Reels.

## Звук
- Музыка синтезирована с нуля скриптом `audio/make_audio.py` (numpy/scipy), сторонних треков и семплов нет.
- Озвучка — синтезированный голос RHVoice «Александр» (`aleksandr-hq`), скрипт `audio/make_voice.py`.
  Он же приглушает музыку под голос и пишет `src/voice-timing.json`, по которому идут субтитры.
- Свой голос: замените `public/soundtrack_vo.wav` и поправьте тайминги в `src/voice-timing.json`.

## Сборка
```bash
npm install
python3 audio/make_audio.py                           # музыка
RHVOICE=$HOME/rhvoice python3 audio/make_voice.py     # голос + микс + тайминг субтитров
npm run render                                        # -> out/ryvok-reel.mp4
node scripts/stills.mjs /tmp/frames 0 60 330 740      # стоп-кадры для проверки
```
Сборка RHVoice описана в шапке `audio/make_voice.py`. Путь к браузеру в `remotion.config.ts`,
`package.json` и `scripts/stills.mjs` указывает на Chromium этого окружения; на своей машине
его можно убрать — Remotion скачает Chrome сам.
