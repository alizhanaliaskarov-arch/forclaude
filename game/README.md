# Звездопад — игра для Google Play

Аркада на одну руку: ведёшь кораблик пальцем, собираешь звёзды и уклоняешься от метеоритов.
Сделана на **HTML5 (Phaser 3)** и упакована в Android-приложение через **Capacitor 8**.
Вся графика и звуки создаются кодом, поэтому чужих ассетов и проблем с лицензиями нет.

## Правила
- ⭐ жёлтая звезда — 1 очко, 💗 розовая — 5 очков.
- Каждые 10 звёзд подряд увеличивают множитель (комбо ×2, ×3…). Пропущенная звезда сбрасывает комбо.
- Метеорит отнимает жизнь. Всего 3 жизни. Со временем скорость растёт.
- Рекорд сохраняется на телефоне.

## Структура
```
src/main.js            настройки игры (720×1280, масштаб под любой экран)
src/scenes/Boot.js     рисует текстуры, общий звёздный фон
src/scenes/Menu.js     главное меню
src/scenes/Play.js     игровой процесс
src/scenes/GameOver.js экран окончания игры
src/audio.js           синтез звуков
src/storage.js         сохранение рекорда
android/               Android-проект (открывается в Android Studio)
store/                 иконка 512×512, баннер 1024×500, скриншоты для Google Play
tools/                 скрипты, которые генерируют иконки и скриншоты
```

## Запуск в браузере
```bash
npm install
```
```bash
npm run dev
```
Откройте показанный адрес. На компьютере можно управлять мышью или стрелками.

## Сборка для Android

Нужны: Node.js 20+, JDK 21 и Android SDK (проще всего поставить **Android Studio**).

1. Собрать веб-часть и скопировать её в Android-проект:
   ```bash
   npm run android
   ```
2. Проверить на телефоне: откройте папку `android/` в Android Studio, подключите телефон с включённой отладкой по USB и нажмите ▶ Run.

### Ключ подписи (один раз)
Google Play принимает только подписанные сборки. Создайте ключ:
```bash
keytool -genkey -v -keystore zvezdopad-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```
Положите `zvezdopad-upload.jks` в папку `android/app/` и создайте файл `android/keystore.properties`:
```
storeFile=zvezdopad-upload.jks
storePassword=ВАШ_ПАРОЛЬ
keyAlias=upload
keyPassword=ВАШ_ПАРОЛЬ
```
⚠️ Не теряйте ключ и пароль и **не загружайте их в Git** (они уже в `.gitignore`). Сохраните копию в надёжном месте.

### Сборка файла для Google Play (.aab)
```bash
cd android && ./gradlew bundleRelease
```
Готовый файл: `android/app/build/outputs/bundle/release/app-release.aab`.

При каждом обновлении игры увеличивайте `versionCode` (1, 2, 3…) и `versionName` в `android/app/build.gradle`.

## Публикация в Google Play

1. **Аккаунт разработчика.** Зарегистрируйтесь на <https://play.google.com/console>, разовый взнос — 25 $. Понадобится подтверждение личности.
2. **Создайте приложение.** «Создать приложение» → название «Звездопад», язык по умолчанию — русский, тип — игра, бесплатно.
3. **Карточка в магазине** (раздел «Основная страница в Google Play»):
   - краткое описание (до 80 символов), например: *Лови звёзды и уклоняйся от метеоритов!*;
   - полное описание (до 4000 символов);
   - значок: `store/icon-512.png`;
   - баннер: `store/feature-1024x500.png`;
   - скриншоты телефона: `store/screen-*.png` (нужно минимум 2).
4. **Обязательные анкеты** (раздел «Контент приложения»):
   - **Политика конфиденциальности** — нужна ссылка на страницу. Игра ничего не собирает, поэтому хватит короткого текста: «Приложение не собирает и не передаёт персональные данные». Его можно разместить, например, на GitHub Pages или Google Sites.
   - **Безопасность данных** — укажите, что данные не собираются и не передаются.
   - **Возрастной рейтинг** — пройдите анкету (насилия и покупок нет).
   - **Целевая аудитория**, **реклама** (рекламы нет), **доступ к приложению** (всё доступно без входа).
5. **Тестирование.** Для новых личных аккаунтов Google требует **закрытое тестирование: минимум 12 тестировщиков в течение 14 дней** подряд. Загрузите `.aab` в «Закрытое тестирование», добавьте адреса тестировщиков (друзья, родственники) и пришлите им ссылку.
6. **Продакшен.** После 14 дней нажмите «Подать заявку на доступ к рабочей версии», затем загрузите `.aab` в «Рабочую версию» и отправьте на проверку. Проверка обычно занимает от нескольких часов до нескольких дней.

## Обновить иконки, splash и скриншоты
```bash
node tools/make-icons.cjs
```
```bash
npm run build && npx vite preview --port 4173
```

```bash
node tools/screenshots.cjs
```
(нужен Playwright: `npm i -D playwright`).

## Готовая тестовая сборка
`builds/zvezdopad-debug.apk` — отладочная версия, чтобы сразу поставить игру на свой телефон (скачайте файл на телефон и откройте; Android попросит разрешить установку из неизвестных источников). В Google Play загружается не она, а подписанный `.aab` (см. выше).
