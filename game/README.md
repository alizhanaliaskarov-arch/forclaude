# Звездопад — игра для Google Play и App Store

Аркада на одну руку: ведёшь кораблик пальцем, собираешь звёзды и уклоняешься от метеоритов.
Сделана на **HTML5 (Phaser 3)** и упакована в приложения для Android и iPhone через **Capacitor 8**.
Вся графика и звуки создаются кодом, поэтому чужих ассетов и проблем с лицензиями нет.

## Правила
- ⭐ жёлтая звезда — 1 очко, 💗 розовая — 5 очков.
- Каждые 10 звёзд подряд увеличивают множитель (комбо ×2, ×3…). Пропущенная звезда сбрасывает комбо.
- Метеорит отнимает жизнь. Всего 3 жизни. Со временем скорость растёт.
- Рекорд сохраняется на телефоне.

## Структура
```
src/main.js            настройки игры (720×1280, масштаб под любой экран)
src/scenes/Boot.js     рисует текстуры, общий звёздный фон
src/scenes/Menu.js     главное меню
src/scenes/Play.js     игровой процесс
src/scenes/GameOver.js экран окончания игры
src/audio.js           синтез звуков
src/storage.js         сохранение рекорда
src/layout.js          подстройка под высоту экрана и вырезы («чёлку»)
android/               Android-проект (открывается в Android Studio)
ios/                   iOS-проект (открывается в Xcode на Mac)
store/                 иконка 512×512, баннер 1024×500, скриншоты для Google Play
store/appstore/        скриншоты для App Store (1320×2868, iPhone 6.9″)
tools/                 скрипты, которые генерируют иконки и скриншоты
```


## Сборка для Android

Нужны: Node.js 20+, JDK 21 и Android SDK (проще всего поставить **Android Studio**).

1. Собрать веб-часть и скопировать её в Android-проект:
   ```bash
   npm run android
   ```
2. Проверить на телефоне: откройте папку `android/` в Android Studio, подключите телефон с включённой отладкой по USB и нажмите ▶ Run.

### Ключ подписи (один раз)
Google Play принимает только подписанные сборки. Создайте ключ:
```bash
keytool -genkey -v -keystore zvezdopad-upload.jks -keyalg RSA -keysize 2048 -validity 10000 -alias upload
```
Положите `zvezdopad-upload.jks` в папку `android/app/` и создайте файл `android/keystore.properties`:
```
storeFile=zvezdopad-upload.jks
storePassword=ВАШ_ПАРОЛЬ
keyAlias=upload
keyPassword=ВАШ_ПАРОЛЬ
```
⚠️ Не теряйте ключ и пароль и **не загружайте их в Git** (они уже в `.gitignore`). Сохраните копию в надёжном месте.

### Сборка файла для Google Play (.aab)
```bash
cd android && ./gradlew bundleRelease
```
Готовый файл: `android/app/build/outputs/bundle/release/app-release.aab`.

При каждом обновлении игры увеличивайте `versionCode` (1, 2, 3…) и `versionName` в `android/app/build.gradle`.

## Публикация в Google Play

1. **Аккаунт разработчика.** Зарегистрируйтесь на <https://play.google.com/console>, разовый взнос — 25 $. Понадобится подтверждение личности.
2. **Создайте приложение.** «Создать приложение» → название «Звездопад», язык по умолчанию — русский, тип — игра, бесплатно.
3. **Карточка в магазине** (раздел «Основная страница в Google Play»):
   - краткое описание (до 80 символов), например: *Лови звёзды и уклоняйся от метеоритов!*;
   - полное описание (до 4000 символов);
   - значок: `store/icon-512.png`;
   - баннер: `store/feature-1024x500.png`;
   - скриншоты телефона: `store/screen-*.png` (нужно минимум 2).
4. **Обязательные анкеты** (раздел «Контент приложения»):
   - **Политика конфиденциальности** — нужна ссылка на страницу. Игра ничего не собирает, поэтому хватит короткого текста: «Приложение не собирает и не передаёт персональные данные». Его можно разместить, например, на GitHub Pages или Google Sites.
   - **Безопасность данных** — укажите, что данные не собираются и не передаются.
   - **Возрастной рейтинг** — пройдите анкету (насилия и покупок нет).
   - **Целевая аудитория**, **реклама** (рекламы нет), **доступ к приложению** (всё доступно без входа).
5. **Тестирование.** Для новых личных аккаунтов Google требует **закрытое тестирование: минимум 12 тестировщиков в течение 14 дней** подряд. Загрузите `.aab` в «Закрытое тестирование», добавьте адреса тестировщиков (друзья, родственники) и пришлите им ссылку.
6. **Продакшен.** После 14 дней нажмите «Подать заявку на доступ к рабочей версии», затем загрузите `.aab` в «Рабочую версию» и отправьте на проверку. Проверка обычно занимает от нескольких часов до нескольких дней.

# Публикация в App Store (iPhone)

iOS-проект уже готов в папке `ios/`: иконка 1024×1024, экран загрузки, только вертикальная ориентация, только iPhone (на iPad игра тоже запустится, но скриншоты для iPad не понадобятся), манифест приватности `PrivacyInfo.xcprivacy` и отметка «не использует шифрование» — без них App Store отклоняет загрузку.

## Что нужно
- **Mac** с последней версией **Xcode** (бесплатно в Mac App Store).
- **Node.js 20+** на Mac (<https://nodejs.org>).
- **Apple Developer Program** — 99 $ в год: <https://developer.apple.com/programs/enroll/>. Регистрация занимает от нескольких часов до пары дней. Без неё можно запускать игру только на своём iPhone для проверки.

## 1. Собрать и открыть проект
```bash
npm install
```
```bash
npm run build && npx cap sync ios
```
```bash
npx cap open ios
```
Откроется Xcode. Первая загрузка зависимостей (Swift Package Manager) займёт минуту.

## 2. Подпись
1. Xcode → Settings → Accounts → «+» → войдите своим Apple ID.
2. Слева выберите проект **App** → цель **App** → вкладка **Signing & Capabilities**.
3. Включите **Automatically manage signing** и выберите свою команду (Team).
4. **Bundle Identifier** — `com.zvezdopad.game`. Если Xcode пишет, что он занят, поменяйте на свой (например `com.ваше-имя.zvezdopad`) и тот же поменяйте в `capacitor.config.json` (`appId`).

## 3. Проверить на своём iPhone
Подключите iPhone кабелем, выберите его вверху Xcode и нажмите ▶. На телефоне включите «Режим разработчика» (Настройки → Конфиденциальность и безопасность), если iOS попросит.

## 4. Создать приложение в App Store Connect
<https://appstoreconnect.apple.com> → «Приложения» → «+» → «Новое приложение»:
- платформа iOS, название «Звездопад» (если занято — добавьте слово, например «Звездопад: космос»);
- основной язык — русский;
- Bundle ID — тот же, что в Xcode;
- SKU — любой, например `zvezdopad1`.

## 5. Загрузить сборку
1. В Xcode вверху выберите устройство **Any iOS Device (arm64)**.
2. Меню **Product → Archive**.
3. В открывшемся окне Organizer → **Distribute App** → **App Store Connect** → **Upload**.
4. Через 10–30 минут сборка появится в App Store Connect (придёт письмо).

При каждом обновлении увеличивайте **Version** (1.0 → 1.1) и/или **Build** (1 → 2) на вкладке General.

## 6. Заполнить карточку
- **Скриншоты iPhone 6.9″**: `store/appstore/screen-*.png` (нужно от 1 до 10). Остальные размеры Apple сделает сама.
- **Описание**, **ключевые слова** (до 100 символов, например: `звёзды,космос,аркада,метеориты,корабль,игра`), **ссылка на поддержку** и **политика конфиденциальности** — обе ссылки обязательны, подойдут те же страницы, что и для Google Play.
- **Категория**: Игры → Аркады.
- **Возрастной рейтинг**: заполните анкету (насилия, покупок, рекламы нет) — получится 4+.
- **Конфиденциальность приложения** («App Privacy»): ответьте «Данные не собираются».
- **Цена**: бесплатно.
- В разделе версии выберите загруженную сборку.

## 7. Отправить на проверку
Нажмите **«Отправить на проверку»**. Обычно проверка занимает 1–2 дня. Если Apple что-то не понравится, придёт письмо с причиной — исправьте и отправьте снова.

Рекомендация: до публикации раздайте игру друзьям через **TestFlight** (вкладка TestFlight в App Store Connect) — это бесплатно и не требует проверки для внутренних тестировщиков. В отличие от Google Play, обязательного тестирования на 14 дней в App Store нет.
