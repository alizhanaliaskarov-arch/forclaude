# Концепт-купе — видеообзор (Remotion, 1920×1080, 1:20, 30 fps)

**Результат:** [`out/concept-car-review.mp4`](out/concept-car-review.mp4) — H.264 + AAC, 80 с.
Исходник — сгенерированное фото варианта B ([`../full/variant-b-1536x1024.png`](../full/variant-b-1536x1024.png)).

Генерация видео в Canva на текущем тарифе недоступна, поэтому обзор собран в Remotion
из одной фотографии: движение камеры, свет, «чертёж» кузова, потоки воздуха, выноски
с подписями деталей — синхронно с русской озвучкой.

| Время | Глава | Что на экране |
|---|---|---|
| 0:00–0:09 | Интро | в темноте зажигаются светодиодные огни, проявляется машина, титр «КОНЦЕПТ-КУПЕ» |
| 0:09–0:21 | 01 Силуэт | кузов затемняется и прорисовывается «чертежом» сканирующей линией: капот, кабина, крыша, задние арки |

| 0:43–0:54 | 04 Колёса | крупный план колеса, вращающееся кольцо; кованые диски, бронзовые суппорты, низкий профиль, протектор |

Закадровый текст и субтитры — [`src/timing.json`](src/timing.json); подписи и их привязка к словам — [`src/events.json`](src/events.json).
В кадре и в тексте только то, что действительно видно на фотографии; никаких выдуманных цифр (мощность, разгон, цена).

## Как это сделано
- **Подготовка кадра** — [`scripts/prepare_image.py`](scripts/prepare_image.py) (OpenCV): ретушь маленького
  значка на носу и орнамента в решётке (ТЗ просило без логотипов), увеличение ×2 для крупных планов,
  маска машины (GrabCut + ручной контур), слой светодиодных огней с размытием-свечением, контуры «чертежа», контур силуэта.
- **Озвучка** — [`audio/make_voice.py`](audio/make_voice.py): RHVoice, голос «Александр» (aleksandr-hq), 112 % скорости.
  Монтаж идёт за голосом: каждая глава длится столько, сколько её текст, и начинается на долю такта музыки (96 BPM).
- **Музыка и звук** — [`audio/make_audio.py`](audio/make_audio.py): всё синтезировано с нуля (numpy/scipy), без сэмплов:
  ре минор, пэды, саб-бас, хрустальное арпеджио в «Свете», ветер в «Аэродинамике», стеклянные колокольчики в «Цвете»,
  включение и выключение огней, капли на мокрой улице, щелчки выносок. Музыка приглушается под голос,
  итоговый микс нормализован до −16 LUFS.
- **Монтаж** — Remotion: [`src/scenes.tsx`](src/scenes.tsx) (7 сцен), [`src/ui.tsx`](src/ui.tsx) (выноски, главы, субтитры, титры),
  [`src/layers.tsx`](src/layers.tsx) (слои фото, свечение, «чертёж», блик по кузову), [`src/camera.ts`](src/camera.ts) (наезды и панорамы).
  Выноски следуют за точками кузова при движении камеры и сами разворачиваются, если подпись не помещается в кадр.

## Как собрать
```bash
npm install
python3 scripts/prepare_image.py      # ассеты кадра (нужен opencv-python-headless, pillow)
sudo apt-get install rhvoice rhvoice-russian
python3 audio/make_voice.py           # озвучка + тайминг -> src/timing.json
python3 audio/make_audio.py           # музыка, эффекты, итоговый микс (numpy, scipy, ffmpeg)
npm run render                        # -> out/concept-car-review.mp4
node scripts/stills.mjs out/stills 0.5 150 428 1219   # контрольные кадры
```
`remotion.config.ts` и `scripts/stills.mjs` указывают на Chromium из `/opt/pw-browsers`; на своей машине
эту строку можно удалить — Remotion скачает браузер сам.
