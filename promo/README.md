# ОДИН — вертикальный промо-ролик (Remotion, 1080×1920, 25 с, 30 fps)

**Результат:** [`out/odin-promo.mp4`](out/odin-promo.mp4) — H.264 + AAC, 25.0 с.

> Репозиторий `forclaude` на момент работы был пустым (ни кода, ни логотипа, ни цветов),
> поэтому продукт вымышленный: **«ОДИН»** — фокус-приложение, которое показывает
> только одну задачу за раз. Для кого: люди, у которых «47 срочных дел» и ни одного сделанного.
> Где: iOS и Android. CTA: «Скачай ОДИН». Сценарий: боль → поворот → решение → CTA.

## Фирменный стиль
Чернильный `#0C0C0F`, крем `#F3EEE3`, сигнальный оранжевый `#FF4A1C`, лайм `#C6FF3D`.
Логотип — вордмарк «ОДИН» (Unbounded 900), в «О» живёт оранжевая точка — «одно дело».
Шрифты: Unbounded (бренд, цифры), Oswald (заголовки), JetBrains Mono (микротекст) — все SIL OFL,
подключены через `@fontsource/*` (файлы лежат в `public/fonts`).

## Раскадровка (всё режется по долям: 120 BPM → 1 доля = 15 кадров)
| Время | Сцена | Приём |
|---|---|---|
| 0–2 с | Хук: «У ТЕБЯ 47 ЗАДАЧ. СДЕЛАНО: 0» | гигантская цифра с кадра 0, RGB-глитч, tear-переход |
| 2–6 с | Хаос: «ПОЧТА. ЧАТЫ. ДЕДЛАЙНЫ. СОЗВОНЫ. ВСЁ ВАЖНО — ЗНАЧИТ НИЧЕГО.» | кинетическая типографика по слову на долю, лавина карточек, нарастающая тряска камеры, смена цвета фона на каждую долю |
| 6–8 с | Поворот: «а если только одно?» | карточки втягиваются в точку, тишина, пульс, ирис-вайп |
| 8–10 с | Дроп: логотип ОДИН | буквы влетают со squash & stretch, камера пролетает сквозь точку в «О» (match-cut) |
| 10–12 с | «ОДНА ЗАДАЧА.» | 3D-телефон в перспективе, параллакс, оранжевое «солнце» |
| 12–14 с | «СДЕЛАЛ. СЛЕДУЮЩАЯ.» | лайм-заливка, свайп, конфетти из фигур, odometer-счётчик |
| 14–16 с | «25 МИНУТ БЕЗ ШУМА.» | кольцо-таймер, уведомления отскакивают от «щита», шторки-переход |
| 16–20 с | «БЕЗ СПИСКОВ. БЕЗ ВИНЫ. БЕЗ ХАОСА.» | 47 точек схлопываются в одну, ирис-вайп из кольца |
| 20–22 с | «ХВАТИТ ЖОНГЛИРОВАТЬ. НАЧНИ С ОДНОГО.» | оранжевая стена бегущих строк под углом |
| 22–25 с | Чистый финал | логотип, «СДЕЛАЙ ОДНО.», кнопка «Скачай ОДИН», iOS / Android |

Весь текст держится в зоне 270–1480 px по вертикали (вне интерфейса Reels сверху и снизу).

## Музыка и звук — источники
**Сторонних треков нет.** Я пробовал взять трек с Mixkit, но из окружения, в котором шла
работа, он недоступен: сетевая политика отдаёт 403 на mixkit.co и другие музыкальные
сайты (archive.org, freepd.com, pixabay, incompetech, FMA). Чтобы не тащить материал
с неясной лицензией, весь саундтрек **синтезирован с нуля** скриптом
[`audio/make_audio.py`](audio/make_audio.py) (numpy/scipy): кик, клэп, хэты, бас, арпеджио,
лид, пэды, риверс-крэши, импакты, вуши, «динь» выполненной задачи, тики таймера.
Никаких семплов, поэтому лицензировать и указывать авторство не нужно; файл — `public/soundtrack.wav`.
Если захотите заменить на трек с Mixkit (Mixkit Free License), положите его в `public/` и
поменяйте `src` у `<Audio>` в `src/Root.tsx`; для синхронизации держите 120 BPM, дроп на 8.0 с.

## Как собрать
```bash
npm install
npm run audio     # пересобрать саундтрек (python3 + numpy + scipy)
npm run render    # -> out/odin-promo.mp4
npm run studio    # превью в Remotion Studio
node scripts/stills.mjs /tmp/frames 0 60 240 745   # быстрые стоп-кадры для проверки
```
`remotion.config.ts` указывает на `headless_shell` из `/opt/pw-browsers`; на своей машине
эту строку можно убрать — Remotion скачает Chrome сам.

## Что проверено после рендера
Кадры вокруг каждого монтажного стыка (±1–4 кадра) и ключевые кадры каждой сцены.
Исправлено по результатам: переполнение «47» и слов по ширине, нечитаемые слова поверх
карточек (теперь на плашках), «ДЕДЛАЙНЫ.» и «СЛЕДУЮЩАЯ.» у края, огромное пятно на финале
(орбитальная точка), перекрытие заголовка уведомлениями, наезд сетки точек на счётчик,
размер/положение точки в «О».
